Prior Work

Literature reviews for the social sciences, built with an AI agent

Search Semantic Scholar and OpenAlex, screen the candidates, check the paper cards your agent fills in, and catch citations that match no paper — all from the VS Code sidebar, with no terminal. What you ask of the agent goes through its chat; what you decide stays yours.

Get the VS Code extension Read the guide

How a survey goes

  1. Scope — research question, period, criteria, depth
  2. Search — Semantic Scholar + OpenAlex
  3. Screen — a page per paper, one key per decision
  4. Chase citations — references and citing papers
  5. Cards — the agent fills them in; you check
  6. Write — the agent writes from the cards
  7. Check and export — citations, DOIs, unchecked cards; HTML

What it does

Screen with one key

A page per candidate with the abstract, the SSCI status, warnings and your criteria. I include, M maybe, X exclude with a reason — and on to the next.

Paper cards you can check

Research question, X, Y, data, identification, findings and limitations for each included paper, with how it was checked. The comparison matrix is built from them.

Search that finds the classics

Semantic Scholar by relevance or boolean bulk search, DOIs and journals verified against OpenAlex, and citation chasing from the included papers.

Fabrication caught mechanically

Every author–year citation in the text must match a registered paper, and no DOI may point to another title. Until then, the export says Draft.

Your agent writes, you decide

Ask Your Agent… copies a ready-made request — fill in the cards, write the text, check and fix — for the chat of Claude Code or another agent. The extension never calls an AI service itself.

No terminal, no setup

Install the extension and create a workspace: it sets up Python (through uv if you have none), your keys go on a settings page, and the workspace goes to a private GitHub repository from the sidebar.

Install

Install the Prior Work extension in VS Code and press Create a Workspace in its sidebar. Nothing else is needed to start: it uses Python 3.10 or later if you have it, and otherwise installs uv, which downloads Python (into your home folder, without administrator rights).

Linux and macOS; on Windows, inside WSL. For the writing, an AI agent that works in VS Code (Claude Code, for example).

From a terminal

The same engine is a command, for agents and scripts:

python3 -m venv .venv
.venv/bin/pip install priorwork
.venv/bin/priorwork init --lang en
./priorwork settings
./priorwork new "minimum wages and employment" --slug minimum_wage
