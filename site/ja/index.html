Priorwork

先行研究サーベイを AI エージェントに任せて、確かめる

エージェント（Claude Code・Antigravity など）にテーマを伝えるだけ。範囲を決め、Semantic Scholar と OpenAlex で探し、理由を残しながら選別し、引用をたどり、論文ごとのカードを書き、サーベイの文章を書いて、すべての引用を検査します。あなたは結果を読み、VS Code のサイドバーで覆したり直したりします。ターミナルも、覚えるコマンドもありません。

VS Code の拡張機能を入れる 手引きを読む

エージェントが止まらずに進めること

  1. 範囲 — RQ・期間・採否の基準・深さ
  2. 検索 — Semantic Scholar ＋ OpenAlex
  3. 選別 — 採否の基準に照らし、理由つきで
  4. 引用をたどる — 参考文献と被引用
  5. カード — 要旨と本文から
  6. 文章 — 背景・論争点・研究の空白まで、カードから
  7. 検査と書き出し — 引用・DOI・未確認のカード。HTML に

できること

普通の言葉で頼むだけ

エージェントのチャットで「〇〇について先行研究を full でまとめて」、またはサイドバーの「新しいサーベイ → エージェントに任せる」。コマンドもスキル名も要りません。最後まで進め、何を決めたかを報告します。

確かめられる論文カード

採用論文ごとに RQ・X・Y・データ・識別戦略・結果・限界と、何で確かめたか。比較マトリクスはカードから自動で作られます。

定番論文も拾う検索

Semantic Scholar の関連度検索とブール演算の bulk 検索。DOI と掲載誌は OpenAlex で照合し、採用論文から引用をたどります。

でっち上げを機械的に検出

文章中の「著者 (年)」はすべて登録済みの論文に、DOI は正しい論文に。そうなるまで、書き出しには「下書き」と出ます。

キー 1 つで覆せる

論文ごとのページに、要旨・SSCI の判定・警告・採否の基準と、エージェントが残した理由。I 採用、M 保留、X 除外。カードも直して保存。エージェントはあなたの変更に従います。

レポート・Zotero・サーバー

レポートは VS Code の中で開けます（SSH でつないだサーバーでも）。Zotero のコレクションをサーベイに結び付ければ、足す DOI はコピー 1 回、本文はそこの PDF から先に読みます。拡張機能が自分で AI のサービスを呼ぶことはありません。

インストール

VS Code に Priorwork の拡張機能を入れ、サイドバーの ワークスペースを作る を押します。始めるのにほかに入れるものはありません。Python 3.10 以上があればそれを使い、無ければ uv を入れて Python を取ってきます（ホームフォルダーに入り、管理者権限は要りません）。

Linux と macOS で。Windows では WSL の中で。それと、VS Code で動く AI エージェント（Claude Code・Antigravity など）を。

ターミナルから

同じエンジンはコマンドとしても使えます（エージェントやスクリプト向け）:

python3 -m venv .venv
.venv/bin/pip install priorwork
.venv/bin/priorwork init --lang ja
./priorwork settings
./priorwork new "最低賃金と雇用" --slug minimum_wage
