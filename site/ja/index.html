Priorwork

先行研究サーベイを AI エージェントに任せて、確かめる

社会科学と臨床研究のために。ふつうの言葉で頼み、VS Code で確かめて直します。

VS Code の拡張機能を入れる クイックガイド

インストール

VS Code の拡張機能を入れて、サイドバーのワークスペースを作るを押すだけです。Python は自動で用意されます（管理者権限は要りません）。VS Code で動く AI エージェント（Claude Code・Antigravity など）が要ります。Linux と macOS、Windows では WSL の中で使えます。

エージェントが止まらずに進めること

  1. 範囲 — RQ・期間・採否の基準・深さ
  2. 検索 — Semantic Scholar ＋ OpenAlex
  3. 選別 — 採否の基準に照らし、理由つきで
  4. 引用をたどる — 参考文献と被引用
  5. カード — 要旨と本文から
  6. 文章 — 背景・論争点・研究の空白まで、カードから
  7. 検査と書き出し — 引用・DOI・未確認のカード。HTML に

できること

普通の言葉で頼むだけ

エージェントのチャットで「〇〇について先行研究を full でまとめて」、またはサイドバーの「新しいサーベイ → エージェントに任せる」。コマンドもスキル名も要りません。最後まで進め、何を決めたかを報告します。

確かめられる論文カード

採用論文ごとに RQ・X・Y・データ・識別戦略・結果・限界と、何で確かめたか。比較マトリクスはカードから自動で作られます。

定番論文も拾う検索

Semantic Scholar の関連度検索とブール演算の bulk 検索。DOI と掲載誌は OpenAlex で照合し、採用論文から引用をたどります。

でっち上げを機械的に検出

文章中の「著者 (年)」はすべて登録済みの論文に、DOI は正しい論文に。そうなるまで、書き出しには「下書き」と出ます。

キー 1 つで覆せる

論文ごとのページに、要旨・SSCI の判定・警告・採否の基準と、エージェントが残した理由。I 採用、M 保留、X 除外。カードも直して保存。エージェントはあなたの変更に従います。

自分の原稿から

書きかけでも出来上がりでも、原稿を渡すと 1 本のレポートに。どこに何を足すか、引用の点検、足りない先行研究をまとめます。詳しく

レポート・Zotero・サーバー

レポートは VS Code の中で開けます（SSH でつないだサーバーでも）。Zotero のコレクションをサーベイに結び付ければ、足す DOI はコピー 1 回、本文はそこの PDF から先に読みます。拡張機能が自分で AI のサービスを呼ぶことはありません。
