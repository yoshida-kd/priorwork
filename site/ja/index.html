Prior Work

AI エージェントと作る、社会科学の先行研究サーベイ

Semantic Scholar と OpenAlex で探し、候補を選別し、エージェントが記入した論文カードを確かめ、どの論文にも対応しない引用を見つける。すべて VS Code のサイドバーで、ターミナルは使いません。エージェントにはチャットで頼み、決めるのはあなたです。

VS Code の拡張機能を入れる 手引きを読む

サーベイの流れ

  1. 範囲 — RQ・期間・採否の基準・深さ
  2. 検索 — Semantic Scholar ＋ OpenAlex
  3. 選別 — 論文ごとのページ、キー 1 つ
  4. 引用をたどる — 参考文献と被引用
  5. カード — エージェントが記入し、あなたが確かめる
  6. 文章 — カードをもとにエージェントが書く
  7. 検査と書き出し — 引用・DOI・未確認のカード。HTML に

できること

キー 1 つで選別

候補ごとのページに、要旨・SSCI の判定・警告・採否の基準。I 採用、M 保留、X 理由つきで除外。決めたら次の候補へ。

確かめられる論文カード

採用論文ごとに RQ・X・Y・データ・識別戦略・結果・限界と、何で確かめたか。比較マトリクスはカードから自動で作られます。

定番論文も拾う検索

Semantic Scholar の関連度検索とブール演算の bulk 検索。DOI と掲載誌は OpenAlex で照合し、採用論文から引用をたどります。

でっち上げを機械的に検出

文章中の「著者 (年)」はすべて登録済みの論文に、DOI は正しい論文に。そうなるまで、書き出しには「下書き」と出ます。

書くのはエージェント、決めるのはあなた

「エージェントに頼む…」が、カードの記入・文章・検査と修正の依頼文をコピーします。Claude Code などのチャットに貼るだけ。拡張機能が自分で AI のサービスを呼ぶことはありません。

ターミナルも準備も不要

拡張機能を入れてワークスペースを作るだけ。Python は自動で用意され（無ければ uv で）、キーは設定のページに、ワークスペースはサイドバーから GitHub の非公開リポジトリへ。

インストール

VS Code に Prior Work の拡張機能を入れ、サイドバーの ワークスペースを作る を押します。始めるのにほかに入れるものはありません。Python 3.10 以上があればそれを使い、無ければ uv を入れて Python を取ってきます（ホームフォルダーに入り、管理者権限は要りません）。

Linux と macOS で。Windows では WSL の中で。文章を書くには、VS Code で動く AI エージェント（Claude Code など）を。

ターミナルから

同じエンジンはコマンドとしても使えます（エージェントやスクリプト向け）:

python3 -m venv .venv
.venv/bin/pip install priorwork
.venv/bin/priorwork init --lang ja
./priorwork settings
./priorwork new "最低賃金と雇用" --slug minimum_wage
